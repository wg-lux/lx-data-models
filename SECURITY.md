# Security Policy

## Supported versions

Security fixes are applied to the latest released version of `lx-dtypes`. The
project is currently pre-1.0, so users should upgrade to the newest release
before reporting an issue that may already be fixed.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately to the maintainer email listed in `pyproject.toml` and include:

- the affected version or commit;
- a minimal reproduction or proof of concept;
- the expected impact; and
- any known workaround.

Avoid including patient data, credentials, access tokens, or other sensitive
material. The maintainers will acknowledge the report, assess its severity, and
coordinate disclosure and a release when appropriate.

For ordinary defects and feature requests, use the
[GitHub issue tracker](https://github.com/wg-lux/lx-data-models/issues).
